# Project Brief

## The Challenge
"I have a vague memory of a photo I took, but I can't find it." 
This project focuses on the failure of semantic photo retrieval when users can only recall disparate, vague fragments of a memory (e.g., "it was a blue car in seattle, maybe raining").

## Business Context
The objective is to validate this problem space through rigorous user research, construct an AI-powered discovery engine to extract patterns from real user frustrations, and prototype an MVP solution based strictly on evidence, not assumption.

## Key Goals
1. Identify the taxonomy of memory cues (what do people remember?)
2. Map the retrieval failure funnel (where do current systems break down?)
3. Prove the opportunity size and propose an evidence-backed solution.
