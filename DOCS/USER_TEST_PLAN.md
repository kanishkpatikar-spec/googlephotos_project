# User Test Plan

## Objective
Validate the MVP against the baseline (standard keyword search) to see if it improves vague-memory retrieval.

## Methodology
- **Participants:** 3 users who struggle with current photo search.
- **Format:** Unmoderated A/B testing (Baseline UI vs. MVP UI).
- **Task:** Retrieve a specific injected "needle in a haystack" photo using only 3 vague clues.

## Metrics to Track
- Time to success
- Number of refinement queries
- Task success rate
